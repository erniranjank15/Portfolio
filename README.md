# Niranjan Kasote — Personal Portfolio

A modern, responsive dark glassmorphic personal portfolio website built with pure HTML5, CSS3, and Vanilla JavaScript.

## 🚀 Live Demo

[personalportfolionk.netlify.app](https://personalportfolionk.netlify.app/)

---

## 🌟 Key Features

- **Dark Glassmorphism Design System**: Sleek `#0d0f14` theme with `#FFBF00` amber/gold glowing accents and glass blurs.
- **Dynamic Typing Subtitle**: Animated role title cycling through Full Stack, React, FastAPI, Node.js, and ML expertise.
- **Active Scrollspy Header**: Sticky glass navigation automatically highlights active section links as you scroll.
- **Interactive Skills & Project Filtering**: Categorized filter tabs (*All*, *Frontend*, *Backend*, *ML*, *Tools*).
- **Expandable Project Details & Modals**: Interactive modal view for deep project details, Live Demos, and GitHub source links.
- **1-Click Quick Copy & Contact Form**: Toast notification feedback when copying contact info and interactive contact form.
- **Fully Responsive**: Optimized for desktop, tablet, and mobile with animated drawer navigation.
